## 자동 수집이 안 되는 기관 (수동 확인 필요)

- **삼척시**: 웹방화벽(WAF)이 자동 요청을 차단("웹방화벽 보안정책에 위배").
- **태백시**: 홈페이지가 프레임/리다이렉트 구조, 계약 목록 URL 미확인.
- **속초시·철원군·화천군·인제군**: 이 작업 환경에서 TLS 핸드셰이크/DNS가 막혀 접속 자체가 실패.
- **횡성군·양양군·고성군**: 계약정보 페이지 경로 미확인(후보 URL 404/400).
- **영월군·양구군**: 세입세출 계약정보공개 목록을 AJAX(jqGrid)로 그려 정적 HTML에 표가 없음.
  브라우저 자동화(Playwright) 또는 내부 API 파라미터 확인이 필요.
